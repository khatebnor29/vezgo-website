# vezgo.app

Landing website for the Vezgo app (Hebrew / Arabic / English), served by GitHub Pages at https://vezgo.app.

- `index.html` — the page, all three languages inside (`?lang=he|ar|en`)
- `download.html` — `vezgo.app/download`: sends iPhone to the App Store, Android to Google Play (the QR code on the page points here)
- Legal pages stay at https://legal.vezgo.app (repo `vezgo-privacy-policy`)

Store links: App Store `id6811210608`, Google Play `com.vehicletest.vehicletset_il`.
